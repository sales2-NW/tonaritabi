# となり旅 by NW LP（公開前プレビュー）

> 海の向こうの、まだ知らない日常へ。

日本と台湾をつなぐ旅行事業「となり旅」の先行登録用ランディングページです。

| ページ | 対象 | ファイル |
|---|---|---|
| 日本語版 | 日本→台湾（はじめての台湾、家族、シニア） | `index.html` |
| 繁體中文版 | 台湾→日本（日本のリピーター、家族、シニア） | `zh-tw/index.html` |

## 公開前の状態について

- **検索よけ：** `robots.txt` と `<meta name="robots" content="noindex, nofollow">` で、検索エンジンに載らないようにしています。
- **写真：** すべて仮のイメージ写真（Unsplash の無料素材）です。自社で撮影した写真に差し替えるまで、正式には公開しないでください。
- **未確定の箇所：** 角かっこの部分は仮の文字です。
- **旅行業登録：** 登録しない方針です。旅行の手配・販売は提携旅行会社が行う前提の文言にしています。
- **リンク：** LINE は流入経路付きのURL（日本語版・繁體中文版で別）。Instagram は準備中のため、リンクを外しています。

## ファイル

- `index.html` — 日本語版（スマホ・PC両対応）
- `zh-tw/index.html` — 繁體中文版（スマホ・PC両対応）
- `css/style.css` — 両ページ共通のスタイル
- `images/` — 掲載写真（撮影者はページ下部に記載）
- `robots.txt` — 検索よけ
- `design/` — デザインカンバスの元ファイル（`.dc.html`）。画像は `images/` のものと同じ写真です

## 公開の手順（GitHub Pages）

1. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` に設定する
2. 数分後に発行されるURLで閲覧できる（繁體中文版は、そのURLの末尾に `zh-tw/` を付ける）
